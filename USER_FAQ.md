# Upfinity Sign — FAQ

The live, searchable version of this FAQ is at `/faq` on the deployed site.

The actual content lives in `lib/content/faq-data.ts` (structured data, not
markdown) — that file is the single source of truth `/faq` renders from.
Edit that file when a question or answer needs to change; this file is
intentionally just a pointer now, not a second copy, so there's no risk
of the two drifting apart the way this exact file did before `/faq`
existed as a real page.
